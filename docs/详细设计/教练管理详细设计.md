## 1.3 数据库物理模型

### 1.3.1 建表语句

```sql
CREATE TABLE `t_coach` (
  `id`          bigint unsigned NOT NULL COMMENT '教练ID',
  `name`        varchar(32)  NOT NULL COMMENT '姓名',
  `avatar_url`  varchar(255) DEFAULT NULL COMMENT '头像URL',
  `intro`       varchar(512) DEFAULT NULL COMMENT '简介',
  `phone`       varchar(32)  DEFAULT NULL COMMENT '联系电话（管理端专用）',
  `gallery`     json DEFAULT NULL COMMENT '相册：JSON数组，最多5个URL',
  `level`     tinyint NOT NULL DEFAULT 1 COMMENT '教练等级：1-普通教练；2-金牌教练',
  `create_by`   bigint unsigned DEFAULT NULL COMMENT '创建人ID',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_by`   bigint unsigned DEFAULT NULL COMMENT '更新人ID',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_coach_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='教练信息表';
```

# 2、接口

## 2.2 教练管理接口

| # | 方法 | 路径 | 功能 | 登录 |
|---:|---|---|---|:---:|
| 1 | GET | `/admin/coaches` | 查询教练列表 | 是 |
| 2 | GET | `/admin/coaches/{coachId}` | 查询教练详情 | 是 |
| 3 | POST | `/admin/coaches` | 新增教练 | 是 |
| 4 | PUT | `/admin/coaches/{coachId}` | 修改教练 | 是 |
| 5 | DELETE | `/admin/coaches/{coachId}` | 删除教练 | 是 |
| 6 | PUT | `/admin/coaches/{coachId}/level` | 设置／取消金牌教练 | 是 |

### 2.2.1 查询教练列表

`GET /admin/coaches`

列表按 `update_time DESC, id DESC` 排序。

#### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Authorization` | header | string | 是 | Bearer <管理端 token>，不能使用会员 token |
| `name` | query | string | 否 | 教练姓名，模糊匹配，最长 32 |
| `pageNum` | query | integer | 是 | 页码，最小 1 |
| `pageSize` | query | integer | 是 | 每页条数，1～100 |

> 返回示例

> 200 Response

```json
{
  "total": 1,
  "rows": [
    {
      "id": "1856739201475237001",
      "name": "王老师",
      "avatarUrl": "https://cdn.example.com/coach/1.jpg",
      "phone": "13800000000",
      "level": 1,
      "levelText": "普通教练",
      "createTime": "2026-10-01 10:00:00",
      "updateTime": "2026-10-01 10:00:00"
    }
  ],
  "code": 200,
  "msg": "查询成功"
}
```

#### 返回结果

| 状态码 | 状态码含义 | 说明 | 数据模型 |
|:---|---|---|---|
| 200 | 成功 | 分页返回教练列表 | `TableDataInfo<CoachListItemVO>` |
| 401 | 登录失效 | 管理端未登录或 token 无效 | `AjaxResult<Void>` |
| 500 | 参数校验失败 | 分页参数缺失，pageNum 小于 1，或 pageSize 不在 1～100 中 | `AjaxResult<Void>` |

### 2.2.3 新增教练

`POST /admin/coaches`

成功不返回新建 ID。新增固定为普通教练（`level = 1`），不接受客户端维护等级。

| `phone` | body | string | 否 | 联系电话，最长 32 |

```json
  "intro": "十年哈他瑜伽经验",
  "phone": "13800000000",
  "gallery": [
    "https://cdn.example.com/coach/1-1.jpg",
    "https://cdn.example.com/coach/1-2.jpg"
  ]
}
```

> 返回示例

> 200 Response

| 状态码 | 状态码含义 | 说明 | 数据模型 |

#### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Authorization` | header | string | 是 | Bearer <管理端 token>，不能使用会员 token |
| `coachId` | path | string | 是 | 教练 ID |
| `name` | body | string | 是 | 教练姓名，非空，最长 32，可重名 |
| `avatarUrl` | body | string | 否 | 头像 URL，最长 255 |
| `intro` | body | string | 否 | 教练简介，最长 512 |
| `phone` | body | string | 否 | 联系电话，最长 32 |
| `gallery` | body | string[] | 否 | 相册图片 URL 数组，最多 5 项 |

### 2.3.3 `CoachCreateDTO` / `CoachUpdateDTO`

两个 DTO 均不定义 `level`；新增由服务端写入 1，普通资料编辑保留原等级。

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|name|string|true|非空，最长 32 字符|姓名|允许与其他教练重名。|
|avatarUrl|string|false|最长 255 字符|头像 URL|教练头像地址。|
|intro|string|false|最长 512 字符|简介|教练介绍。|
|phone|string|false|最长 32 字符|联系电话|教练联系电话。|
|gallery|string[]|false|最多 5 项|相册|图片 URL 数组；数量由服务层校验。|

### 2.3.4 `CoachQuery`

列表筛选与分页：`name`、`pageNum`、`pageSize`。

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|name|string|false|none||教练名称|
|pageNum|integer|true|最小 1|页码|必填。|
|pageSize|integer|true|1～100|每页条数|必填。|

### 2.3.5 等级接口入参

单个查询参数 `level`，仅接受 `1`／`2`，不另建 DTO；等级码及文案由 `CoachLevelEnum` 统一定义。

# 4、运行流程

## 4.1 查询列表
1. Controller 校验 `CoachQuery`（`pageSize` 上限 100）。
2. Service 调 DAO 分页查询（只 select `id/name/avatar_url/phone/level/审计时间`），按 `update_time DESC, id DESC` 排序。
3. 转 `CoachListItemVO`，按 `CoachLevelEnum` 补齐 `levelText`，与等级码成对返回。

## 4.2 查询详情
1. Service 按 ID 查询；不存在 → `404`。
2. 反序列化 `gallery` 为 `List<String>`，按 `CoachLevelEnum` 补齐 `levelText`，转 `CoachDetailVO` 返回。

## 4.3 新增教练
1. Controller 校验 `name` 非空、长度与各字段长度。
2. Service 校验 `gallery` 元素数 ≤ 5；超过 → `409`。
3. 序列化 `gallery` 为 JSON 字符串，显式写入 `level = 1` 后插入；主键与审计字段由公共机制处理。请求中的等级字段不参与新增。

## 4.4 修改教练
1. Service 按 ID 查询；不存在 → `404`。
2. 校验 `gallery` 元素数 ≤ 5；超过 → `409`。
3. 仅全量覆盖 `name`、`avatar_url`、`intro`、`phone`、`gallery`，不更新 `level`；返回最新详情，包含原等级及文案。

## 4.5 删除教练

1. Service 按 ID 查询教练；不存在返回 `404`。
2. 按 ID 删除教练记录，返回统一成功响应。



## 4.6 设置／取消金牌教练

1. Controller 校验 `coachId` 格式与 `level` 必填，目标等级只能是 1 或 2；其他值返回 `500`。
2. `CoachService.setLevel` 调 DAO 按 ID 查询教练；不存在返回 `404`。
3. 当前等级与目标相同时返回成功；否则更新 `level`，公共审计字段由统一机制填充。
4. 返回统一成功响应。
