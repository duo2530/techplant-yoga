# 详细设计记录

**用途：** 记录详细设计的**评审意见、设计决策与变更原因**。设计正文在 `详细设计.md`，本文件只记过程与理由，回答「为什么这么设计」「谁提的、什么时候改的」。

**约定**

| 项 | 说明 |
|---|---|
| 记录范围 | 只记**已生效**的评审意见与决策；尚未拍板的待确认项在 `详细设计.md` 的 1.4（字段）与 2.5（接口）里，不进本文件 |
| 一条记录包含 | 时间 / 来源 / 意见 / 处理 / 理由 / 影响文件 |
| 与正文的关系 | **正文是唯一权威**；本文件不复制正文内容，只留理由与变更轨迹 |
| 同步要求 | 正文改了，这里必须同步登记一条；不要只改正文不记录 |

## R06（2026-09-22）日志设计的两条口径

| 项 | 内容 |
|---|---|
| 来源 | 编写第 6 章时的设计判断（需评审） |
| 口径一 | **查询类接口不写业务日志**。查询是高频只读操作，逐次埋点会淹没需要审计的写操作；「谁查了什么、耗时、状态码」由公共模块的统一访问日志覆盖。仅保留慢查询（建议 500 毫秒）WARN |

## R11（2026-09-22）响应体系统一为若依 AjaxResult / TableDataInfo

| 项 | 内容 |
|---|---|
| 来源 | 用户决策：「改用若依 AjaxResult 统一全局」 |
| 处理 | ① **删除**本模块自定义的 `ApiResponse`、`BusinessException`、`GlobalExceptionHandler`（与框架同名类冲突，且与框架响应口径不一致）、`CourseReferencedException`；② 单条接口改返回 `AjaxResult`（`{code, msg, data}`，成功 `code=200`），列表接口改返回 `TableDataInfo`（`{total, rows, code, msg}`）；③ 业务失败改抛框架的 `ServiceException`（带业务码 404 / 409），由框架自带的 `com.ruoyi.framework.web.exception.GlobalExceptionHandler` 统一转换；④ 正文口径写进 2.1.3、2.1.4、2.3.1、2.3.2、2.4，2.5 的 A3 由「建议方案」转为「已确认」；⑤ 3.x 与 4.1.3.1 里被替换的类名同步更新 |
| 理由 | 与 RuoYi 管理端既有约定一致（**HTTP 状态码固定 200，业务结果一律看 `code`**），前端只判断一个字段；同时避免同一工程里出现两套响应体与两个全局异常处理器 |
| 影响 | `详细设计.md` 2.1.3、2.1.4、2.2 章首、2.3.1、2.3.2、2.4、2.5(A3)、3.1.1、3.1.2、3.1.3、3.1.4、3.2.1、3.2.2、4.1.3.1；代码 `ruoyi-yoga`（controller / service / 异常处理）与配套单元测试 |

**遗留（需要在后续确认，均已如实写进正文 2.4）：**

- **409 的结构化阻塞明细取消**：若依的 `AjaxResult` 只能承载 `code/msg/data`，框架处理器不会附带 `data`，因此原设计的 `data:{scheduleCount, bookingCount}` 改为写进 `msg`。若前端需要结构化明细，需要在**框架的全局异常处理器**上做扩展（会同时影响 `sys_*` 接口，需另行评估）。
- **参数校验失败的业务码是 500**（不是 400）：走的是框架 `MethodArgumentNotValidException` 分支，`msg` 为具体字段提示。若要定为 400，同样需要改框架处理器。
- **框架的 `RuntimeException` 分支会把异常 `message` 放进 `msg`**（例如数据库异常会带出表名与语句片段），本版沿用框架行为，未做收敛。

## 由 R01~R03 归纳出的活动图口径

已写进 `详细设计.md` 第 4 章章首：

> **画什么：** 活动图只画**业务步骤与其落表操作**。横切基础设施（全局异常处理）与框架自动行为（主键生成、审计字段填充）不属于业务步骤，不出现在活动图里。表操作保留 —— 模板明确要求活动图体现「类与**表**之间的交互」。
>
> **怎么写：** 泳道标题可以用类名或表名；**泳道里每一步用中文业务语言描述，不写方法名、不写 SQL、不写框架名**。

两条判据：

1. **这一步是不是「这个功能要实现的事」？** 是 → 画；只是「框架顺手做的事」或「全局兜底的事」→ 不画。
2. **这行字是给业务看的还是给代码看的？** 「谁做」用类名（泳道标题），「做什么」用中文（泳道内容）。
