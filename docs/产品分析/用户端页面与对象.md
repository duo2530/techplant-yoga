## 当前实现口径与截图差异（金牌教练与约教练页）

> 本节记录 add-home-gold-coaches 后的当前实现口径，与上文截图对象的差异逐项列出。截图来自对标产品，样例人物、星级评分与固定课程数据不作为本产品数据来源。

### 首页：金牌教练栏目

- 位置：门店卡之后，一次展示**平台全部**金牌教练卡片；不分页、不截取前三位，也不提供「更多教练」入口。
- 卡片字段：教练头像、姓名、简介；无头像或头像加载失败使用中性占位，简介为空显示「暂无介绍」。截图中的「教练头衔（金牌）」在实现中体现为栏目的等级筛选（`level = 2`），不再单独展示头衔。
- 栏目独立加载：区分加载中、空（「暂无金牌教练」）与失败可重试；不影响门店卡与换店。
- 与当前门店无关：切换门店不改变金牌列表；平台没有可选门店时栏目照常展示。
- 点击卡片携带该教练的字符串 ID 进入约教练页。

### 约教练页（P9）

- 页面定位：由截图对应的「单教练资料 ＋ 近期排课」页面构成；不再是全部教练列表，也不是只读课表。
- 资料区：渐变背景、白色圆角资料面板、头像、姓名、简介、相册；简介为空显示「暂无教练简介」，相册为空显示「暂无教练相册」，相册图片可预览。
- 排课区：课种 Tab 四类（默认团课），标明「当前门店 · 未来14天」，日期窗口由服务端按业务时区计算。
- 排课卡：课程封面、课程名称、课种、难度、日期与起止时间、教室、剩余名额、状态；跨日时显示日期。
- 分页：默认每页 10 条，提供显式「加载更多」按钮；切换课种从第一页重新加载。
- 返回刷新：从课程详情或其它页面返回本页触发 `onShow` 时，重新拉取**当前课种**的排课第一页（保留当前课种 Tab 与门店），剩余名额、可约状态与新增场次随之更新；不再只在门店变化时刷新。
- 异常：无有效门店提示「请先在首页选择门店」但资料与相册仍可见；无场次显示「暂无排课」；网络失败可重试；不存在的教练提示「教练不存在或已被删除」，不使用其他教练资料兜底。
- 排课卡点击按排课 ID 进入既有课程详情页并沿用预约流程。

### 与截图的视觉差异

| 项目 | 截图 | 当前实现 |
|---|---|---|
| 课程卡日期 | 只有时间（原型为单日课表） | 显示日期与时间，跨日可区分 |
| 窗口说明 | 无 | 排课区标明「当前门店 · 未来14天」 |
| 星级评分 | 封面内 3～5 星装饰 | 不实现，原型样例不作为真实数据 |
| 加载方式 | 长列表 | 显式「加载更多」按钮（小程序保留触底兼容） |
| 导航栏 | 微信系统导航栏 | 小程序保留系统导航栏；H5 由页面渲染标题栏，不绘制微信胶囊 |
| 相册 | 「暂无教练相册」空态 | 有相册时可预览，保持保存顺序 |
