# 一水·瑜伽普拉提（小程序）· 功能清单

**版本：v1** ｜ 依据 **21 张真机截图** 反推

> **口径说明**
> 1. 按**业务能力**拆分，一条 = 一个完整可交付的功能；
> 2. **只列自研功能**，不含微信原生能力（位置授权、手机号快速验证、地图、转发分享）；
> 3. 「功能描述」中标**待确认**的，属登录门后或数据为空、截图上无法验证的部分。
