# 项目基础设施

| -------- | ----------------------------------- |
| 脚手架   | Spring Boot 2.5.15 / JDK 1.8        |

| 权限认证 | Spring Security + JWT               |
| 工具类 | backend/ruoyi-common/src/main/java/com/ruoyi/common/utils |
| 统一响应包装 | AjaxResult     |
| 分页对象，分页参数解析 | TableDataInfo  |
| 全局异常处理 | GlobalExceptionHandler、ServiceException |
| 基础类 | BaseController |
| 常量 / 枚举 / 通用配置 | backend/ruoyi-common/src/main/java/com/ruoyi/common/enums               |
| 注解 | @Log、@PreAuthorize |
