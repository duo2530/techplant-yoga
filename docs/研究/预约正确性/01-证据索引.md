## 官方与原创技术资料

以下均于 2026-10-17 访问。MySQL 链接明确为 8.0，Spring 明确为项目使用的 5.3.39；工具手册与代码版本不同的地方单独说明。

| 编号 | 原始资料 | 支持的结论及边界 |
|---|---|---|
| E05 | [MySQL 8.0 Locking Reads](https://dev.mysql.com/doc/refman/8.0/en/innodb-locking-reads.html) | 显式事务内锁定读用于后续修改；锁到事务结束；普通快照读仍可读取旧版本。不能由此推导整个业务线性化 |
| E06 | [Consistent Nonlocking Reads](https://dev.mysql.com/doc/refman/8.0/en/innodb-consistent-read.html) | RR 普通读可能持续使用旧快照，当前读与快照读不能混为同一可见性视图 |
| E07 | [Locks Set by Different SQL Statements](https://dev.mysql.com/doc/refman/8.0/en/innodb-locks-set.html) | 锁与扫描索引范围有关；唯一等值命中与范围／未命中行为有差异。具体 DAO 锁面仍须执行计划与双会话验证 |
| E08 | [InnoDB Error Handling](https://dev.mysql.com/doc/refman/8.0/en/innodb-error-handling.html) | 死锁回滚整事务；锁等待超时默认主要回滚当前语句。应用必须明确回滚并在新事务重试，不能盲目从失败语句继续 |
| E09 | [CHECK Constraints](https://dev.mysql.com/doc/refman/8.0/en/create-table-check-constraints.html) | 8.0.16 起执行 CHECK；可约束单行域，不能声明跨表求和守恒；NULL 的 UNKNOWN 要用 NOT NULL 补足 |
| E10 | [CREATE INDEX](https://dev.mysql.com/doc/refman/8.0/en/create-index.html) | 唯一索引允许多个 NULL；据此可设计仅活跃记录非 NULL 的生成列唯一约束；迁移前先清理坏数据 |
| E11 | [Spring 5.3.39 事务章节](https://docs.spring.io/spring-framework/docs/5.3.39/reference/html/data-access.html#transaction-declarative-annotations) | 代理调用、传播和回滚规则决定真实事务边界；自调用不会凭内层注解建立新事务 |
| E12 | [Testcontainers MySQL](https://java.testcontainers.org/modules/databases/mysql/) | 真实 MySQL 的隔离依赖；当前在线文档示例可能面向新版，项目以 1.21.4 API 为准 |
| E13 | [JUnit 5.7.2 用户指南](https://docs.junit.org/5.7.2/user-guide/) | 参数化、生命周期与并发测试组织；本项目测试失败要查报告，JUnit 不自动保证数据库线程交错 |
| E14 | [jqwik 原始用户指南](https://jqwik.net/docs/current/user-guide.html) | 属性、生成器、seed 与 shrinking；当前页面为 1.10.2，不在本项目添加该版本依赖；若引入要先核查 Java 8 兼容版本 |
| E15 | [Herlihy & Wing 1990 原论文](https://cs.brown.edu/~mph/HerlihyW90/p463-herlihy.pdf) | 合法顺序历史还须保持已完成操作的实时先后；最终计数正确不足以证明历史正确 |
| E16 | [Lamport《Specifying Systems》作者页](https://lamport.azurewebsites.net/tla/book.html)、[TLC 实现](https://github.com/tlaplus/tlaplus) | 可把状态和动作写成有限规格探索；本次没有运行 TLC，也没有声称有限模型覆盖 JVM／InnoDB |
