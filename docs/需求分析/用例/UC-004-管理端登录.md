# 用例：管理端登录

## 概览

**用例编号：** UC-004
**用例名称：** 管理端登录
**主要参与者：** 平台管理员
**参与方：** 账号与登录（业务模块）
**业务目标：** 让**平台管理员**进入管理端，作为其余全部管理端用例（[UC-005](UC-005-维护门店资料.md) ~ [UC-009](UC-009-维护排课.md)）的前置条件。
**涉及模块：** 账号与登录
**状态：** 已确认

> 依据：[`业务规则.md`](../../需求文档/业务规则.md) v2.1。

## 前置条件

- 管理端入口可访问。
- 一期管理端**只有一个角色**：平台管理员。

## 主成功场景

1. 管理员打开管理端，进入登录页；
2. 输入**用户名**与**密码**；
3. 应用校验通过后进入管理端；
4. 管理员可访问**门店管理、教室管理、教练管理、课程管理、排课管理**五个模块；
5. 管理员后续访问管理端任意页面时，登录态保持有效直至失效。

## 替代流程

- **A1 用户名或密码错误**：拒绝登录并提示凭据不正确。
- **A2 未登录访问管理端任意页面或接口**：拒绝访问并引导登录。
- **A3 登录态失效**：下一次请求被拒绝，回到登录页。
- **A4 一期只有一个管理角色**：不区分平台管理员与门店管理员；**不设菜单权限、按钮权限与数据范围**，登录后即可读写全部数据。
- **A5 一期不做用户端登录**：用户端免登录，与本用例无关。

## 后置条件

### 成功后的状态

- 管理员获得管理端访问能力；
- 可执行门店、教室、教练、课程、排课的全部维护动作。

### 失败后的状态

- 未获得访问能力；
- 不产生任何业务数据变更。

## 业务规则

| 规则编号 | 在本用例中的作用 |
|---|---|
| BR-全局-003 | 一期只有平台管理员一个管理角色，可读写全部数据；不设菜单／按钮权限与数据范围 |
| BR-全局-004 | 管理端必须登录，登录方式为用户名 ＋ 密码 |
| BR-全局-001 | 一期只有用户端与管理端两个端 |
| BR-全局-002 | 用户端免登录（与本用例形成对照） |
| BR-全局-006 | 主体不存在或已删除时一律拒绝并提示不存在 |
