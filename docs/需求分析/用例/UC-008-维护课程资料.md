# 用例：维护课程资料

## 概览

**用例编号：** UC-008
**用例名称：** 维护课程资料
**主要参与者：** 平台管理员
**参与方：** 课程、排课（业务模块）
**业务目标：** 维护**平台级**的课程主数据（查询、新增、修改、删除），为排课提供可选课程，为用户端排课卡片与课程详情页提供课程资料。
**涉及模块：** 课程、排课
**状态：** 已确认

> 依据：[`业务规则.md`](../../需求文档/业务规则.md) v2.1。

## 前置条件

- 管理员已登录管理端（[UC-004](UC-004-管理端登录.md)）。

## 主成功场景

1. 管理员查询**课程列表**（可按课程名称、课种筛选）与课程详情；
2. **新增课程**：填写课程名称、课种、课程封面（**单图**）、课程介绍、课程难度（**1~5 星**）；应用校验课程名称**全平台唯一**；
3. **修改课程**：修改上述资料；名称同样校验唯一（排除自身）；
4. **删除课程**：**物理删除**；删除前校验该课程名下**没有未结束、且状态为待上架或已上架的排课**；
5. 应用返回维护结果，管理员在列表中核对。

## 替代流程

- **A1 课程重名**：拒绝新增或修改（课程为平台级，唯一范围是全平台）。
- **A2 课种不在枚举内**：拒绝（枚举为**团课、精品课、私教课、特色课**四类）。
- **A3 难度超出 1~5 星**：拒绝。
- **A4 课程名下仍有未结束且待上架／已上架的排课**：拒绝删除，并给出数量。
- **A5 只有已取消或已结束的历史排课引用该课程**：**不阻塞删除**；删除后这些历史排课上的课程显示为空，管理端做空值兜底。
- **A6 统计无法完成**（统计异常）：拒绝删除，**不降级放行**。
- **A7 课程没有启用／停用状态**：不提供状态维护入口，下架通过删除实现。
- **A8 课程不提供多图**：封面只保留单图。
- **A9 课种在排课时做快照**：改课种**不追溯**（既有排课的课种不变）；但**难度、封面、介绍**实时取课程，所以**改难度会改变既有排课的展示**。
- **A10 一期不设课程「展示排序」字段**：用户端没有首页热门区。
- **A11 课程不归属门店**：不建门店字段，不做「排课门店 = 课程门店」的一致性校验。
- **A12 课程不存在或已删除**：拒绝查询详情、修改与删除。
- **A13 「私教课」课种保留但一期不使用**：可以建私教课课程，但一期没有私教排课与私教预约。

## 后置条件

### 成功后的状态

- 新增与修改结果落库，课程可被排课表单查询到；
- 删除为物理删除，删除后该课程不再出现在排课表单的可选项中；其历史排课上的课程显示为空。

### 失败后的状态

- 课程数据保持原值；
- 既有排课不受影响。

## 业务规则

| 规则编号 | 在本用例中的作用 |
|---|---|
| BR-课程-001 | 课程为平台级主数据，不归属门店 |
| BR-课程-002 | 课程名称全平台唯一 |
| BR-课程-003 | 课种四类（团课／精品课／私教课／特色课） |
| BR-课程-004 | 难度 1~5 星 |
| BR-课程-005 | 课程封面只保留单图 |
| BR-课程-006 | 课程字段范围 |
| BR-课程-007 | 课程没有启用／停用状态 |
| BR-课程-008 | 课程可删除且为物理删除，须过删除门禁 |
| BR-课程-009 | 课种在**排课时做快照**（改课种不追溯）；难度／封面／介绍实时取课程 |
| BR-课程-010 | 不设展示排序，用户端没有首页热门区 |
| BR-全局-009 | 删除门禁统一口径：只统计未结束且待上架／已上架的排课 |
| BR-全局-006 | 主体不存在或已删除时一律拒绝 |
| BR-全局-007 | 引用检查失败即拒绝，不降级放行 |
| BR-全局-005 | 一期不纳入私教排课与私教预约 |
