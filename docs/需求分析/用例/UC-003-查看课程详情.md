# 用例：查看课程详情

## 概览

**用例编号：** UC-003
**用例名称：** 查看课程详情
**主要参与者：** 用户（**免登录**）
**参与方：** 课程、排课、教练、门店、教室（业务模块）
**业务目标：** 从一张排课卡片进入，查看该次排课对应的**课程资料**与**本次上课信息**，了解人数与剩余名额。
**涉及模块：** 课程、排课、教练、门店、教室
**状态：** 已确认

> 依据：用户端界面以 `docs/产品分析/` 的实测截图为准（对应截图中的「课程预约」页）。

## 前置条件

- 用户位于约课页，且所选排课**在用户端可见**（即状态**不是「待上架」**，[UC-002](UC-002-浏览约课页.md)）。
- 用户端**免登录**。

## 主成功场景

1. 用户在约课页点击一张排课卡片；
2. 应用打开该排课对应的**课程详情页**；
3. 页面展示**课程资料**：课程封面、课种、课程难度、课程介绍；
4. 页面展示**本次上课信息**：上课时间、教练（姓名、头像、**简介**）、门店、教室；
5. 页面展示**人数信息与状态**：最大人数、最低开课人数、预约人员、剩余名额、排课状态；
6. 用户点击「**立即预约**」；
7. 应用进入**预约确认页**，用例结束。

## 替代流程

- **A1 不可直接预约**：满员但仍可排队时按钮显示「排队」，点击同样进入预约确认页；既不可预约也不可排队时按钮显示排课状态或「排队已满」，不可点。
- **A2 预约人员**：无人预约时该区块显示**空态**。
- **A4 该排课已不可见**（被下架，即回到「待上架」）：按**不可查看**处理并给出提示，回到约课页。**已取消与已结束仍可查看**，但「立即预约」不可点。
- **A5 课种取排课快照，其余取课程当前值**：**课种**以排课保存的**快照**为准；**难度、封面、介绍**取课程**当前值**，课程资料被修改后本页展示随之变化。
- **A6 课程资料已被删除**：课程被未结束且待上架或已上架的排课引用时不允许删除，因此正常情况下不会出现该页面缺课程资料的情况；若数据异常，页面做空值兜底。

## 后置条件

### 成功后的状态

- 用户看到该次排课的课程资料与上课信息；
- **不产生任何服务端数据变更**（不生成预约、不扣减任何数据）。

### 失败后的状态

- 排课不可见时给出提示并回到约课页；不改变任何业务数据。

## 业务规则

| 规则 |
|---|
| 用户端浏览免登录，预约前需登录 |
| 点击排课卡片进入课程详情页 |
| 课程详情页的要素清单；「立即预约」进入预约确认页 |
| 用户端可查看**非「待上架」**的排课 |
| 剩余名额 = 最大人数 − 已预约人数 |
| **课种做快照**（本页课种取排课快照）；难度／封面／介绍取课程当前值 |
| 课程封面单图；课程字段范围 |
| 教练为平台级，仅作为本次上课信息展示 |
| 排课所选教室归属门店与排课门店一致 |
