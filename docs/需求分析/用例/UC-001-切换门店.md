# 用例：切换门店

## 概览

**用例编号：** UC-001
**用例名称：** 切换门店
**主要参与者：** 用户（**免登录**）
**参与方：** 门店、教练、排课（业务模块）
**业务目标：** 在**首页**选定"当前门店"，使用户端后续的约课页按该门店查询与展示排课；首页同时展示**平台级**金牌教练栏目，为用户提供进入单个教练"约教练"页的入口。
**涉及模块：** 门店、教练、排课
**状态：** 已确认

> 依据：`docs/产品分析/` 的实测截图与跳转梳理；金牌教练栏目与约教练页的口径见[教练管理详细设计](../../详细设计/教练管理详细设计.md)与[用户端接口详细设计](../../详细设计/用户端接口详细设计.md) §2.2.14～§2.2.16。`业务规则.md` 当前仅有标题、规则内容缺失，本用例引用的规则编号沿用既有编号，新增口径不虚构规则编号。

## 前置条件

- 用户端已进入**首页**（**不需要登录**）。

## 主成功场景

1. 用户进入首页，首页展示**门店卡**：门店名称、所在区域、门店地址；
2. 门店卡下方展示「**金牌教练**」栏目：一次展示**平台全部**金牌教练卡片（头像、姓名、简介），与当前门店、当前门店是否有排课均无关；栏目独立加载，失败可重试，且不影响门店卡与换店；
3. 用户点击任一金牌教练卡片，携带该教练的字符串 ID 进入其「**约教练**」页，查看教练头像、姓名、简介、相册与当前门店未来 14 天的排课；
4. 用户点击门店卡上的「**换店**」，查看门店列表（只返回**未删除**的门店，**分页加载**，展示门店名称、所在区域、门店地址）；列表支持**按所在区域筛选**与**按门店名称／地址关键字搜索**；
5. 用户选择另一家门店；
6. 应用把该门店设为**当前门店**，并由客户端记住该选择（**不登录、不落服务端**）；
7. 返回首页，门店卡更新为新门店；金牌教练栏目仍按**平台范围**展示，不因换店变化；
8. 用户进入约课页时，按**新门店**查询排课（[UC-002](UC-002-浏览约课页.md)）。

## 替代流程

- **A1 首次进入、没有历史选择**：默认选中门店列表中的**第一家**门店。
- **A2 系统里没有任何门店**：门店列表显示**空态**，首页门店卡也显示空态；金牌教练栏目**照常展示**，仍可进入教练资料页。
- **A3 所选门店已被删除**（切换过程中被管理端删除）：本次选择失败并提示，回到门店列表。
- **A4 一期不做登录拦截**：未登录即可查看门店列表并切换门店、浏览金牌教练与约教练页；不跳转登录页。
- **A5 门店没有启用／停用状态**：门店列表不展示状态，也不提供筛选。
- **A6 筛选或搜索没有命中**：列表显示空态；**不影响当前门店**，用户可以清空条件或直接返回。
- **A7 金牌教练列表加载失败**：栏目显示失败状态与重试入口，重试成功后替换为最新列表；门店卡与换店操作保持可用。
- **A8 平台没有金牌教练**：栏目显示「暂无金牌教练」空态，不展示模拟人物或固定样例数据。
- **A9 管理员取消金牌后返回首页**：首页再次显示时重新拉取金牌列表，被取消的教练不再出现在栏目中；已打开的该教练资料页仍可访问。
- **A10 卡片对应的教练已被删除**：进入约教练页时提示「教练不存在或已被删除」，提供返回入口，不使用其他教练资料兜底。

## 后置条件

### 成功后的状态

- 当前门店已更新，并被客户端记住；
- 用户端约课页按新门店查询排课；
- 首页金牌教练栏目保持平台级展示，不随当前门店变化；
- **不产生任何服务端数据变更**。

### 失败后的状态

- 当前门店保持原值；
- 门店数据不受影响。

## 业务规则

| 规则编号 | 在本用例中的作用 |
|---|---|
| BR-全局-002 | 用户端免登录，只提供浏览能力（浏览金牌教练与约教练页同样免登录） |
| BR-全局-010 | 默认选中第一家门店；切换结果由客户端记住，不落服务端 |
| BR-用户端-002 | **门店切换在首页完成**；不做登录拦截 |
| BR-用户端-004 | 首页提供进入约课页的入口；切换门店后约课页按新门店重新查询 |
| BR-门店-001 | 门店是浏览与排课的服务地点；切换门店后只展示该门店的排课 |
| BR-门店-002 | 门店列表只返回未删除的门店；**支持按所在区域与名称／地址关键字筛选**；无门店时显示空态 |
| BR-门店-005 | 所在区域为固定枚举（上海市的 16 个市辖区） |
| BR-门店-007 | 门店字段范围，含门店图片单图 |
| BR-门店-008 | 门店没有状态，不提供状态维护 |
| BR-全局-006 | 门店不存在或已删除时拒绝并提示不存在 |

> **本次变更废止的旧口径：** 原 BR-用户端-001「一期用户端只有首页、约课页、课程详情页三个页面」与原 BR-用户端-003「首页只做门店切换」不再适用。首页在门店卡之后增加平台级「金牌教练」栏目，并新增单教练「约教练」页（P9）；新口径见[教练管理详细设计](../../详细设计/教练管理详细设计.md)、[用户端接口详细设计](../../详细设计/用户端接口详细设计.md)与 `openspec/changes/add-home-gold-coaches/` 下的规格。`业务规则.md` 的规则内容当前缺失，上表沿用既有编号，未新增规则编号。
