# 用例：浏览约课页

## 概览

**用例编号：** UC-002
**用例名称：** 浏览约课页
**主要参与者：** 用户（**免登录**）
**参与方：** 排课、课程、教练、门店、教室（业务模块）
**业务目标：** 按**当前门店 ＋ 日期**查看该门店可看的排课卡片，作为进入课程详情页的入口。
**涉及模块：** 排课、课程、教练、门店、教室
**状态：** 已确认

> 依据：[`业务规则.md`](../../需求文档/业务规则.md) v2.1；用户端界面与跳转以 `docs/产品分析/` 的实测截图与跳转梳理为准（约课页的品类 Tab 与"今天起 14 天"日期条均与截图一致）。

## 前置条件

- 已确定**当前门店**（[UC-001](UC-001-切换门店.md)）。
- 用户端**免登录**。

## 主成功场景

1. 用户从首页进入**约课页**；
2. 页面展示**当前门店**与**日期条**（今天起 14 天，**默认选中今天**）；
3. 页面展示**课种 Tab 四类**：团课／精品课／私教课／特色课；
4. 应用按固定条件查询排课：**未删除 ＋ 状态不等于「待上架」＋ 门店等于当前门店 ＋ 日期等于所选日期**（日期按排课的**日期列**判定，不用开始／结束时间拼）；
5. 每张**排课卡片**展示：课程名称、课种、难度、上课时间、教练、门店、教室、剩余名额、**状态**；
6. 用户切换日期或课种 Tab，列表随之刷新；
7. 用户点击某张排课卡片，进入课程详情页（[UC-003](UC-003-查看课程详情.md)）。

## 替代流程

- **A1 该门店该日期没有排课**：显示空态「暂无数据」。
- **A2 「私教课」Tab**：一期**没有私教排课数据**，显示空态。
- **A3 排课处于「待上架」**：不返回、不展示。**已取消与已结束照常返回**，并在卡片上标注状态。
- **A4 剩余名额**：一期没有预约，已预约人数恒为 0，**剩余名额恒等于最大人数**；**已结束与已取消的卡片置灰且不可发起预约**。
- **A5 用户端展示排课状态**：卡片上标注**「可约／已结束／已取消」**；**不出现**管理端才有的「待上架」。
- **A6 门店没有任何可看的排课**：整个列表显示空态。

## 后置条件

### 成功后的状态

- 用户看到当前门店、当前日期的排课卡片列表；
- **不产生任何服务端数据变更**，不生成预约。

### 失败后的状态

- 查询失败时列表为空并给出提示；不改变任何业务数据。

## 业务规则

| 规则编号 | 在本用例中的作用 |
|---|---|
| BR-全局-002 | 用户端免登录，只提供浏览能力 |
| BR-用户端-004 | 约课页按当前门店查询 |
| BR-用户端-005 | 约课页按当前门店 ＋ 日期展示排课卡片；日期条 14 天，默认今天 |
| BR-用户端-006 | 课种 Tab 四类；一期「私教课」Tab 展示空态 |
| BR-用户端-007 | 排课卡片的要素清单 |
| BR-用户端-008 | 点击卡片进入课程详情页 |
| BR-排课-015 | 用户端展示**除「待上架」以外**的排课（已上架、已结束、已取消都可见） |
| BR-排课-016 | 固定过滤条件：未删除、状态不等于「待上架」、门店等于当前门店 |
| BR-排课-017 | 日期范围为今天起 14 天，默认选中今天 |
| BR-排课-018 | 剩余名额 = 最大人数 − 已预约人数，一期恒等于最大人数 |
| BR-排课-020 | 管理端看状态；**用户端也展示排课状态** |
| BR-课程-001 | 用户端看到的「课程列表」实质是该门店的排课列表 |
| BR-门店-001、BR-门店-002 | 按门店查询；门店须未删除 |
| BR-教室-007 | 教室被删除后历史排课不失效，仅教室显示为空 |
