# 管理端功能清单

**版本：v1**（2026-09-20）

| 模块  | 子模块   | 功能     | 功能描述                      |
| --- | ----- | ------ | ------------------------- |
| 门店  | 门店管理  | 查询门店   | 查询系统中的门店及门店基本信息           |
| 门店  | 门店管理  | 新增门店   | 创建新的门店信息                  |
| 门店  | 门店管理  | 修改门店   | 修改门店名称、联系方式、营业时间、地址、图片等信息 |
| 门店  | 门店管理  | 设置门店状态 | 控制门店是否正常对外提供服务            |
| 课程  | 课程管理  | 查询课程   | 查询系统中的课程及课程基本信息           |
| 课程  | 课程管理  | 新增课程   | 创建课程基础信息                  |
| 课程  | 课程管理  | 修改课程   | 修改课程名称、类型、介绍、难度等课程信息      |
| 课程  | 课程管理  | 设置课程状态 | 控制课程是否可继续用于排班或展示          |
| 排班  | 排班管理  | 查询排班   | 查询各门店、教练在指定时间范围内的课程安排     |
| 排班  | 排班管理  | 创建排班   | 为指定课程设置教练、门店、时间、场地、人数等安排  |
| 排班  | 排班管理  | 修改排班   | 修改已有课程排班信息                |
| 排班  | 排班管理  | 取消排班   | 取消尚未完成的课程排班               |
| 预约  | 预约管理  | 查询预约   | 查询用户对课程的预约记录及状态           |
| 预约  | 预约管理  | 查询预约详情 | 查询某个课程场次的预约人数、预约用户等信息     |
| 体验课 | 体验申请  | 查询体验申请 | 查询用户提交的体验课申请              |
| 体验课 | 体验申请  | 审核体验申请 | 对体验课申请进行审核并设置通过或拒绝结果      |
| 教练  | 教练管理  | 查询教练   | 查询教练及其基本资料                |
| 教练  | 教练管理  | 新增教练   | 创建教练账号和基础资料               |
| 教练  | 教练管理  | 修改教练   | 修改教练头像、简介、联系方式等信息         |
| 教练  | 教练管理  | 设置教练状态 | 设置教练是否可继续参与排班和授课          |
| 用户  | 用户管理  | 查询用户   | 查询平台注册用户及基本资料             |
| 用户  | 用户管理  | 查询用户详情 | 查询用户会员、会员卡、积分、合同、体测等关联信息  |
| 会员  | 会员管理  | 查询会员   | 查询用户会员等级及会员状态             |
| 会员  | 会员等级  | 配置会员等级 | 配置不同会员等级、名称、金额、有效期等规则     |
| 会员  | 会员权益  | 配置会员权益 | 配置不同会员等级对应的折扣、优惠券、礼包等权益   |
| 会员卡 | 会员卡管理 | 查询会员卡  | 查询用户持有的会员卡及状态             |
| 优惠券 | 优惠券管理 | 查询优惠券  | 查询系统中的优惠券配置及用户持券情况        |
| 优惠券 | 优惠券管理 | 配置优惠券  | 配置优惠内容、适用条件、有效期等规则        |
| 礼包  | 礼包管理  | 查询礼包   | 查询礼包及礼包内容                 |
| 礼包  | 礼包管理  | 配置礼包   | 配置礼包名称、组成、奖励类型、数量、参考价值等内容 |
| 积分  | 积分管理  | 查询积分   | 查询用户积分及相关记录               |
| 合同  | 合同管理  | 查询合同   | 查询用户合同及合同状态               |
| 体测  | 体测管理  | 查询体测记录 | 查询用户已有的体测记录               |
| 体测  | 体测管理  | 新增体测记录 | 为用户新增体测数据                 |
| 公告  | 公告管理  | 查询公告   | 查询已经发布或保存的公告              |
| 公告  | 公告管理  | 发布公告   | 创建并发布公告内容                 |
| 公告  | 公告管理  | 修改公告   | 修改公告内容                    |
| 活动  | 活动管理  | 查询活动   | 查询系统中的活动                  |
| 活动  | 活动管理  | 发布活动   | 创建并发布活动内容                 |
| 活动  | 活动管理  | 修改活动   | 修改活动内容                    |
| 消息  | 消息管理  | 查询消息   | 查询系统产生或发送的消息              |
| 消息  | 消息管理  | 发送消息   | 向指定用户、教练或用户群体发送消息         |
