# 教练端功能清单

**版本：v1**（2026-09-20）

| 模块 | 子模块  | 功能     | 功能描述                  |
| -- | ---- | ------ | --------------------- |
| 账号 | 登录认证 | 登录账号   | 教练通过手机号、微信或其他方式登录教练端  |
| 教练 | 个人资料 | 查询个人信息 | 查询教练头像、姓名、简介、擅长领域等资料  |
| 教练 | 个人资料 | 修改个人信息 | 修改允许教练自行维护的个人资料       |
| 课程 | 我的课程 | 查询课程   | 查询自己负责或参与授课的课程        |
| 课程 | 课程安排 | 查询课程安排 | 查询自己的上课日期、时间、门店、教室、预约等安排 |
| 学员 | 学员信息 | 查询学员信息 | 查询与当前课程相关的学员基本信息      |
| 体测 | 学员体测 | 查询体测记录 | 查询学员已有的体测记录           |
| 体测 | 学员体测 | 录入体测记录 | 为学员录入新的体测数据           |
| 消息 | 消息通知 | 查询消息   | 查询课程调整、预约变化等消息通知      |
