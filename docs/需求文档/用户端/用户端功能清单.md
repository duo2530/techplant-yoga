# 用户端功能清单

**版本：v1**（2026-09-20）

| 模块 | 子模块 | 功能 | 功能描述 |
|---|---|---|---|
| 账号 | 登录认证 | 微信快捷登录 | 用户授权微信手机号后完成身份认证并登录系统 |
| 账号 | 登录认证 | 手机号密码登录 | 用户使用手机号和密码完成身份认证并登录系统 |
| 账号 | 登录认证 | 确认用户协议 | 用户同意用户协议和隐私政策后方可进行登录或注册 |
| 账号 | 账号注册 | 注册账号 | 用户通过手机号、短信验证码和密码创建账号 |
| 账号 | 短信验证 | 获取短信验证码 | 向指定手机号发送用于注册或密码重置的短信验证码 |
| 账号 | 密码管理 | 重置密码 | 用户通过手机号和短信验证码验证身份后设置新密码 |
| 公告 | 公告查询 | 查询公告 | 查询并展示当前可供用户查看的公告内容 |
| 课程 | 课程查询 | 查询课程列表 | 根据门店、日期、课程类型等条件查询课程 |
| 课程 | 课程查询 | 查询课程详情 | 查询课程名称、教练、时间、地点、难度、剩余名额等信息 |
| 课程 | 课程预约 | 创建课程预约 | 用户选择可预约课程并创建预约记录 |
| 课程 | 课程预约 | 查询课程预约 | 查询用户已有的课程预约及当前预约状态 |
| 课程 | 体验课 | 提交体验课申请 | 用户填写门店、姓名、手机号、留言等信息提交体验课申请 |
| 课程 | 体验课 | 查询体验课申请 | 查询用户提交的体验课申请及审核状态 |
| 课程 | 课程咨询 | 电话咨询课程 | 用户通过课程页面提供的联系电话联系门店进行课程咨询 |
| 教练 | 教练查询 | 查询教练列表 | 查询当前可展示的教练列表 |
| 教练 | 教练查询 | 查询教练详情 | 查询教练头像、简介、相册及关联课程等信息 |
| 个人中心 | 个人资料 | 查询个人信息 | 查询用户头像、昵称、会员等级、手机号等个人资料 |
| 个人中心 | 账号管理 | 注销账号 | 用户申请注销当前账号 |
| 个人中心 | 消息 | 查询消息 | 查询当前用户收到的消息通知 |
| 个人中心 | 会员卡 | 查询会员卡 | 查询用户持有的会员卡信息 |
| 个人中心 | 优惠券 | 查询优惠券 | 查询用户拥有的优惠券信息 |
| 个人中心 | 礼包 | 查询礼包 | 查询用户拥有的礼包信息 |
| 个人中心 | 积分 | 查询积分 | 查询用户当前积分信息 |
| 个人中心 | 合同 | 查询合同 | 查询与当前用户相关的合同及合同状态 |
| 个人中心 | 体测 | 查询体测记录 | 查询用户已有的体测记录 |
| 个人中心 | 协议 | 查询用户协议 | 查询并展示当前用户协议 |
| 个人中心 | 协议 | 查询隐私协议 | 查询并展示当前隐私政策 |
