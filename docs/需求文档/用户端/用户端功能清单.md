# 用户端功能清单

**版本：v1**（2026-09-20）

| 模块  | 子模块  | 功能      | 功能描述                       |
| --- | ---- | ------- | -------------------------- |
| 账号  | 登录认证 | 微信快捷登录  | 用户通过微信授权完成登录               |
| 账号  | 登录认证 | 手机号登录   | 用户通过手机号完成登录                |
| 账号  | 账号注册 | 注册账号    | 用户通过手机号完成账号注册              |
| 账号  | 密码管理 | 重置密码    | 用户验证身份后重新设置密码              |
| 公告  | 公告   | 查询公告    | 用户查看平台或门店公告                |
| 课程  | 课程查询 | 查询课程    | 用户根据门店、日期、课种等条件查询课程及课程信息 |
| 课程  | 课程预约 | 预约课程    | 用户选择课程并完成预约                |
| 课程  | 课程预约 | 查询课程预约  | 用户查询自己的课程预约及状态             |
| 课程  | 体验课  | 申请体验课   | 用户向指定门店提交体验课申请             |
| 课程  | 体验课  | 查询体验课申请 | 用户查询体验课申请及审核状态             |
| 教练  | 教练   | 查询教练    | 用户查询教练资料、相册及相关课程           |
| 用户  | 个人资料 | 查询个人信息  | 查询用户头像、昵称、会员等级、手机号等信息      |
| 用户  | 账号管理 | 注销账号    | 用户申请注销自己的账号                |
| 消息  | 消息   | 查询消息    | 用户查询收到的消息通知                |
| 会员权益  | 会员权益   | 查询会员权益    | 用户查看会员权益，各个等级，各个等级的权益包内容                |
| 会员卡 | 会员卡  | 查询会员卡   | 用户查询自己持有的会员卡               |
| 优惠券 | 优惠券  | 查询优惠券   | 用户查询自己拥有的优惠券               |
| 礼包  | 礼包   | 查询礼包    | 用户查询自己拥有的礼包                |
| 积分  | 积分   | 查询积分    | 用户查询自己的积分                  |
| 合同  | 合同   | 查询合同    | 用户查询自己的合同及合同状态             |
| 体测  | 体测   | 查询体测记录  | 用户查询自己的体测记录                |
