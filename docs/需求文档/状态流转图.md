# 状态流转图

**文档版本：v2.0（重置版）**（2026-10-01）

> **一期门店、教室、课程都没有状态**（`BR-门店-008`、`BR-教室-003`、`BR-课程-007`），需要状态流转的只有**排课**。
> 本文件原名「课程状态流转图」，现描述**排课状态流转**；建议更名为 `排课状态流转图.md`。

## 1. 落库状态只有三个

**待上架 / 已上架 / 已取消**。「已结束」**不落库**，由「结束时间不晚于当前时间」推导（`BR-排课-010`）。

```plantuml
@startuml
title 排课状态流转（一期）

[*] --> 待上架 : 新增排课（默认）

待上架 --> 已上架 : 上架
已上架 --> 待上架 : 下架
已上架 --> 已取消 : 取消

已取消 --> [*]

note right of 待上架
  用户端不可见
  可编辑、可物理删除
end note

note right of 已上架
  用户端可见
  不可编辑，须先下架
  不可删除，须先下架回到待上架
end note

note bottom of 已取消
  终态
  不可编辑、不可删除
  用户端仍可见
end note

@enduml
```

## 会员卡状态图

```mermaid
stateDiagram-v2
    [*] --> 未激活 : 用户注册 / 商家开卡
    
    未激活 --> 正常使用 : 激活 / 首次充值
    未激活 --> 已注销 : 超时未激活关闭

    state 正常使用 {
        [*] --> 权益可用
        权益可用 --> 积分变动 : 消费/签到
        权益可用 --> 等级调整 : 达到升降级标准
    }

    
    正常使用 --> 已过期 : 超出服务有效期
    正常使用 --> 已注销 : 用户主动退会 / 严重违规销户

    
    已过期 --> 正常使用 : 用户续费 / 激活
    已过期 --> 已注销 : 超过留存期自动销户

    已注销 --> [*]

```
